# 🏗️ سامانه جامع مدیریت سه‌گانه کارگاه (انبارداری، پیمانکاران و ماشین‌آلات)

> **یک راهکار مهندسی، مدرن و کارآمد برای ترازگیری مالی، مدیریت انبارداری مقداری کارگاهی، حقوقی پیمانکاران جزء و ناوگان لجستیک ترابری سنگین پروژه به همراه‌ خروجی‌های استاندارد اکسل و چاپ تجمیعی سازمانی.**

این سامانه به صورت اختصاصی جهت نظارت دقیق بر کارگاه‌های عمرانی، پروژه‌های فعال ساختمانی، انبارداری توزیع کالا و مدیریت هم‌زمان چندین پیمانکار جزء و ناوگان سنگین و سبک ترابری طراحی شده است. تمرکز اصلی نرم‌افزار بر دقت حسابداری کارگاهی، کاهش خطای انسانی در ثبت متمم‌ها و کنترل موازنه مالی است.

---

## 📌 ویژگی‌های کلیدی سامانه (Key Features)

### ۱. 📦 مدیریت انبارداری مقداری کارگاهی (Inventory Management)
* **پایش تراز لحظه‌ای کالاها**: محاسبه آنی حجم ورودی، خروج و مانده واقعی موجودی انبار.
* **ثبت دقیق قبوض انبار**: ثبت کارهای ورودی و خروجی بر اساس واحدهای استاندارد (لیتر، کیلوگرم، شاخه، متر مکعب و ...).
* **سیستم هشدار کسر موجودی**: پایش لحظه‌ای مواد مصرفی حیاتی کارگاه (نظیر میلگرد، سیمان، گازوئیل ناوگان).
* **صدور قبوض انبار استاندارد**: قابلیت مشاهده و چاپ فیش تایید متریال ورودی به انبار و خروجی کارگاهی.

### ۲. 👤 حسابرسی و پایش مالی پیمانکاران جزء (Contractor Financial Engine)
* **شناسنامه‌بندی قراردادها**: ثبت مبلغ اولیه پیمان، متمم‌ها و الحاقیه‌های کاهش یا افزایش سقف قرارداد کار.
* **محاسبه اتوماتیک کسورات قانونی**: کسر سپرده حسن انجام کار (معمولاً ۱۰٪)، بیمه سهم پیمانکار (معمولاً ۵٪)، مالیات پیش‌فرض کارگاهی و استهلاک پیش‌پرداخت‌ها.
* **هشدارهای حفاظتی متمم ۲۵٪**: اعلام هشدار قرمز در صورت فراتر رفتن حجم کارکردهای پیمانکار از محدوده مجاز الحاقیه‌ها به منظور جلوگیری از بروز مشکلات حقوقی.
* **موازنه عملکرد لحظه‌ای**: ترازگیری آنی میان صورت‌وضعیت‌های تایید شده، پرداخت‌های علی‌الحساب و صافی بدهکاری/طلبکاری کارگاه.

### ۳. 🚚 کارکرد ناوگان ماشین‌آلات و ترابری (Machinery & Logistics Fleet)
* **دو ساختار محاسباتی فعال**: تعریف مدل همکاری بصورت ساعتی (کارکرد کارگاهی متغیر) یا روزانه/ماهانه ثابت.
* **سیاهه‌نویسی فعالیت‌های روزانه**: ثبت کارکرد کارگاهی به صورت دوره‌ای و محاسبه خودکار درآمد هر دستگاه بر اساس نرخ مبنا.
* **پکیج گزارش مالی تراز مالکین**: تجمیع درآمد چندین خودرو یا دستگاه متعلق به یک مالک و ترازگیری با پرداختی‌های مالی جهت تعیین مانده طلب صافی مالک ناوگان.

### ۴. 🖨️ ماژول چاپ هوشمند سازمانی (Advanced Institutional Printing)
* **سربرگ‌های کاملاً اختصاصی کارگاهی**: تهیه گزارش‌های مالکین و پیمانکاران بر روی فرمت‌های چاپی استاندارد و رسمی.
* **فیلترهای پیشرفته چاپ**: امکان انتخاب گزارش تراز تجمیعی تکی یا کل پیمانکاران/مالکین با اعمال فیلتر ماهیت یا مبنای اجاره.
* **طراحی Responsive چاپی**: پنهان‌سازی بخش‌های ناوبری، منوها و دکمه‌های کنترل برنامه در حین فرآیند چاپ مرورگر و خروجی PDF تمیز.

### ۵. 📊 امنیت، پشتیبان‌گیری و خروجی اکسل (Data Management)
* **خروجی اکسل (Excel Export)**: قابلیت تولید و دانلود فایل‌های اکسل راست‌چین (RTL) حاوی کلیه آمار و ترازهای مالی پیمانکاران و ناوگان برای مدیران ارشد سازمان.
* **سیستم پشتیبان‌گیری (JSON Backup)**: امکان دانلود فایل پشتیبان کامل از تمامی دیتابیس‌های کارگاهی و بازیابی مجدد اطلاعات در کسری از ثانیه بدون پاک شدن داده‌ها.

## 🛠️ فناوری‌های مورد استفاده (Tech Stack)

به منظور ایجاد کارایی فوق‌العاده بالا، طراحی زیبا و عملکرد یکپارچه آفلاین و وب، این سامانه از مدرن‌ترین ابزارها استفاده می‌کند:

* **React 18 + TypeScript**: تضمین پایداری نوع داده‌ها، سرعت لود بالا و کامپوننت‌های ماژولار.
* **Vite**: توسعه سریع، بهینه‌سازی کدهای استاتیک و سرعت لود فوق‌العاده.
* **Tailwind CSS**: طراحی رابط کاربری خلاق، مینیمال، چشم‌نواز و سازگار با حالت‌های ریسپانسیو صفحه.
* **Framer Motion**: انیمیشن‌های نرم حرکتی، افکت‌های ملایم جابجایی بین منوها و باز شدن مودال‌ها.
* **Lucide React**: آیکون‌استایل‌های مهندسی، مدرن و هماهنگ بصری در کل صفحات.

## 🚀 راهنمای نصب و راه‌اندازی (Quick Start)

### پیش‌نیازها
مطمئن شوید که ابزار `Node.js` (نسخه ۱۸ به بالا) بر روی سیستم شما نصب است.

### مراحل راه‌اندازی در محیط محلی

۱. **کلون کردن پروژه**:
   ```bash
   git clone https://github.com/your-username/machinery-contractor-inventory.git
   cd machinery-contractor-inventory
   ```

۲. **نصب وابستگی‌ها**:
   ```bash
   npm install
   ```

۳. **اجرای سرور توسعه (Local Dev Mode)**:
   ```bash
   npm run dev
   ```
   *پس از اجرای این دستور، سامانه روی نشانی وب محلی [http://localhost:3000](http://localhost:3000) در دسترس خواهد بود.*

۴. **تهیه نسخه نهایی تولید (Build & Production)**:
   ```bash
   npm run build
   ```
   *خروجی نهایی و بهینه‌شده به صورت فایل‌های استاتیک در پوشه `/dist` ایجاد می‌گردد.*

## 📂 ساختار ماژولار پروژه (Directory Structure)

کدهای سامانه کاملاً ساختاریافته، تمیز و تفکیک شده پیاده‌سازی شده‌اند:

```text
├── src/
│   ├── components/
│   │   ├── ContractorDashboard.tsx  # ماژول حسابداری پیمانکاران جزء و صورت‌وضعیت‌ها
│   │   ├── ContractorProfileView.tsx # پرونده فنی و ریزگردشکارهای پیمانکار
│   │   ├── DocumentForm.tsx         # فرم استاندارد ورود و خروج کالا و اقلام انبار
│   │   ├── MachineryDashboard.tsx   # مدیریت ناوگان لجستیک و موازنه تراز مالکین
│   │   └── MachineryProfileView.tsx  # ریزصورت پرونده کارکرد و پرداختی هر خودرو
│   ├── utils/
│   │   ├── excelExport.ts            # پکیج فایلهای خروجی اکسل راست‌چین شده
│   │   └── formatters.ts             # موتور فرمت تومن/ریال و مبدل یونیکد جلالی
│   ├── App.tsx                       # کامپوننت اصلی ناوبری، پیشخوان سه‌گانه و مانیتورینگ
│   ├── main.tsx                      # درگاه و لودکننده اصلی ری‌اکت در صفحه وب
│   └── index.css                     # کدهای استایل سرتاسری و استایپوگرافی Tailwind
├── package.json                      # وابستگی‌ها و تمپلیت فرآیند توسعه لود وب
└── README.md                         # مستندات و راهنمای پروژه
```
