# CivilSync (SiteFlow-PMIS) 🛠️
### سامانه هوشمند و یکپارچه امور کارگاه و دفتر فنی

یک سیستم یکپارچه، مدرن و تحت وب برای مدیریت اطلاعات پروژه (PMIS) که موازنه دقیق میان سه رکن اصلی کارگاه‌های عمرانی (کالای انبار، تراز مالی پیمانکاران، و کارکرد ماشین‌آلات) را بدون پیچیدگی‌های سیستم‌های مالی و حسابداری بزرگ برقرار می‌کند. این برنامه به طور ویژه برای کارگاه‌ها و پروژه‌های زیربنایی و خطوط انتقال طراحی شده است.

---

## 🚀 ویژگی‌های اصلی سیستم (Modules)

### ۱. ماژول انبارداری مقداری (Inventory Management)
* **روکش پویای انبار:** نمایش موجودی لحظه‌ای مصالح و تجهیزات تخصصی پروژه در یک نگاه.
* **ثبت سریع اسناد:** دسترسی سریع به دکمه‌های شناور `(+) سند ورود` و `(-) سند خروج` در داشبورد اصلی.
* **کاردکس کالا:** تاریخچه کامل و تفکیک‌شده ورود و خروج هر کالا همراه با نام تحویل‌دهنده/گیرنده.
* **تمرکز صرفاً مقداری:** بدون درگیر شدن با ارزش‌گذاری‌های ریالی (FIFO/LIFO) جهت حفظ سرعت و سادگی کارکرد در محیط کارگاه.

### ۲. ماژول حساب جاری پیمانکاران (Contractors Finance)
* **روکش مالی لایو:** پایش همزمان کل کارکرد ناخالص، مجموع کسورات، مبالغ پرداختی و مانده طلب نهایی هر پیمانکار.
* **اتوماسیون کسورات کارگاهی:** محاسبه خودکار **۱۰٪ سپرده حسن انجام کار** و **۵٪ سپرده بیمه** روی مبالغ ناخالص ورودی.
* **مدیریت وضعیت:** ثبت جزء به جزء صورت‌وضعیت‌ها و لیست پرداختی‌ها به همراه تاریخ و توضیحات در پروفایل اختصاصی هر پیمانکار.

### ۳. ماژول کارکرد مالی ماشین‌آلات (Machinery Tracking)
* **پایش هوشمند کارکرد:** مدیریت ماشین‌آلات بر اساس نوع قرارداد (ساعتی یا روزانه/ماهانه).
* **فرمول محاسباتی دقیق دوره:** * برای قراردادهای ساعتی: `تعداد ساعت کارکرد × نرخ پایه`.
  * برای قراردادهای ماهانه: فرمول هوشمند تقسیم نرخ ماهانه بر تعداد روزهای واقعی ماه (**۳۱ روزه** برای نیمه اول سال و **۳۰ روزه** برای نیمه دوم سال) جهت استخراج کارکرد دقیق روزهای فعال.
* **کاهش خطای انسانی:** حذف شیت‌های تودرتوی اکسل و محاسبه لایو مانده طلب مالکان ماشین‌آلات.

## 🛠️ پشته فناوری (Tech Stack)

* **Front-end:** React.js, Tailwind CSS (RTL Direction)
* **Back-end:** Python (FastAPI) / Node.js (Express)
* **Database:** SQLite (سبک، سریع و قابل حمل)
* **UI/UX:** کاملاً مدرن، واکنش‌گرا (Responsive) همراه با فونت اختصاصی **وزیرمتن (Vazirmatn)**

---

## 💎 امکانات کلیدی و جانبی (Key Features)

* **خروجی و ورودی اکسل (Excel I/O):** امکان خروجی گرفتن از روکش‌های مالی و موجودی انبار به صورت فایل `.xlsx` و قابلیت آپلود اکسل برای راه‌اندازی اولیه کالاها.
* **نسخه پشتیبان (Backup):** امکان دانلود مستقیم فایل دیتابیس SQLite از داخل پنل تنظیمات با یک کلیک.
* **قالب چاپ اختصاصی:** بهینه‌سازی صفحات اسناد جهت خروجی PDF و چاپ استاندارد (A4/A5) برای اخذ امضای فیزیکی در کارگاه.

git clone [https://github.com/your-username/civil-sync.git](https://github.com/your-username/civil-sync.git)

# Setup Backend
cd civil-sync/backend
pip install -r requirements.txt
uvicorn main:app --reload

# Setup Frontend
cd ../frontend
npm install
